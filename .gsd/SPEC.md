# SPEC.md — ALODANAX Admin Panel: Local Publish Mode (Part 1B)

> **Status**: `FINALIZED`
> **Methodology**: GSD (Get Shit Done) Spec-Driven Development
> **Scope**: Admin panel manages ONLY the hackathon page (domains + problem statements). Local publish mode.

---

## 1. Project Context & Vision

ALODANAX is an annual IT/CS college TechFest website.
- **Frontend Architecture**: Static HTML5 + CSS3 + vanilla JS. No build step, no public live backend. Public pages: `index.html`, `events.html`, `hackathon.html`, `team.html`, `contact.html`.
- **Target Page**: `hackathon.html`. Its challenge tracks/problem statements are dynamically driven by a static JSON export generated by the local admin panel.
- **Local Publish Concept**:
  - The admin panel runs locally on `http://127.0.0.1:5000/admin/`.
  - Content changes in domains and problem statements are written to SQLite.
  - When the admin clicks "Publish to website" or runs `flask --app wsgi export`, the backend atomically generates `data/hackathon-domains.json` at the project root.
  - The website host/repository serves `data/hackathon-domains.json` statically. `hackathon.html` fetches this file with zero live backend dependency on the public site.

## 2. Goals & Non-Goals

### Goals
1. **Local-Only Admin Panel**: Flask 3 + SQLite running exclusively on `127.0.0.1:5000`. Refuse non-local binding.
2. **Static JSON Export**: Atomically export published domains and problem statements to `data/hackathon-domains.json`.
3. **Pending-Changes Indicator**: Track content hash of last exported payload versus current published state. Clearly signal "Website file is up to date" or "You have unpublished changes. Click Publish to website, then upload data/hackathon-domains.json to your site".
4. **Three Export Triggers**:
   - Dashboard card "PUBLISH TO WEBSITE" with `POST /api/admin/export`
   - Download JSON alternative via `GET /admin/export/download`
   - CLI command: `flask --app wsgi export`
5. **Database Backup CLI**: `flask --app wsgi backup-db` creating timestamped copies in `backend/backups/`.
6. **Robust Frontend Integration in `hackathon.html`**:
   - Fetches `data/hackathon-domains.json` with a 5-second `AbortController` timeout.
   - Strictly validates JSON shape.
   - If missing, unreachable, or invalid: silently retains inline `HACKATHON_DATA.domains`.
   - If valid but empty (`domains: []`): displays friendly empty state `"Problem statements will be announced soon."` (does not show inline placeholders).
   - Strict `escapeHtml()` sanitization on all dynamic values to prevent XSS.
7. **Strict Security Posture**:
   - Argon2id password hashing with dummy verification to prevent timing attacks.
   - Account lockout (5 failed attempts = 15 min lock).
   - Rate limiting on login and mutating endpoints.
   - Flask-WTF CSRF protection on all mutating routes.
   - Security headers (CSP, nosniff, DENY framing, same-origin referrers).
   - Audit logging for admin actions and exports.

### Non-Goals (Out of Scope)
- NO hosting/cloud deployment (no Gunicorn, Procfile, Render, Neon, reverse proxy).
- NO public API (`/api/public/...`), NO CORS.
- NO team module, NO photo upload pipeline, NO Pillow image processing.
- NO changes to public pages other than the `hackathon.html` controller script.
- NO touching `SHARED:` blocks in HTML files.

## 3. Data Model Specifications

- **Admin**:
  - `id`: Integer primary key
  - `username`: String(32), unique, regex `^[a-z0-9_.-]{3,32}$`
  - `password_hash`: String(255), Argon2id hash
  - `failed_logins`: Integer, default 0
  - `locked_until`: DateTime (UTC), nullable
  - `last_login_at`: DateTime (UTC), nullable
  - `created_at`: DateTime (UTC), default `utc_now`

- **Domain**:
  - `id`: Integer primary key
  - `slug`: String(140), unique, regex `^[a-z0-9-]+$`
  - `name`: String(120), not null
  - `short_description`: String(300), not null
  - `sort_order`: Integer, default 0
  - `is_published`: Boolean, default False
  - `created_at`: DateTime (UTC)
  - `updated_at`: DateTime (UTC)
  - Computed `tag`: e.g. `DOMAIN 01` based on `sort_order`

- **ProblemStatement**:
  - `id`: Integer primary key
  - `domain_id`: Integer, ForeignKey('domains.id', ondelete='CASCADE'), not null
  - `code`: String(16), unique, regex `^[A-Z]{1,4}-\d{1,3}$`
  - `title`: String(150), not null
  - `difficulty`: Enum('EASY', 'MEDIUM', 'HARD', 'EXTREME'), not null
  - `description`: String(1500), not null
  - `expected_outcome`: String(800), not null
  - `sort_order`: Integer, default 0
  - `is_published`: Boolean, default False

- **ExportState**:
  - `id`: Integer primary key (singleton row, id=1)
  - `last_exported_hash`: String(64), SHA-256 of last exported JSON
  - `last_exported_at`: DateTime (UTC), nullable
  - `updated_at`: DateTime (UTC)

- **AuditLog**:
  - `id`: Integer primary key
  - `admin_id`: Integer, nullable
  - `action`: String(64) (e.g. `login`, `domain_create`, `export`, etc.)
  - `entity_type`: String(64)
  - `entity_id`: Integer, nullable
  - `ip`: String(64)
  - `created_at`: DateTime (UTC)

## 4. Export JSON Contract

Target path: `data/hackathon-domains.json` (configurable via `EXPORT_PATH`, default `../data/hackathon-domains.json`).
Structure:
```json
{
  "schemaVersion": 1,
  "updatedAt": "2026-11-20T10:00:00Z",
  "domains": [
    {
      "slug": "domain-1",
      "name": "AI & Autonomous Systems",
      "tag": "DOMAIN 01",
      "shortDescription": "...",
      "problemStatements": [
        {
          "id": "PS-01",
          "title": "...",
          "difficulty": "HARD",
          "description": "...",
          "expectedOutcome": "..."
        }
      ]
    }
  ]
}
```
Rules:
- Includes ONLY published domains (`is_published=True`) and published statements (`is_published=True`).
- Ordered by `sort_order` ascending.
- Domains with 0 published statements are omitted.
- Formatted with 2-space indentation and trailing newline.
- Written atomically via temporary file rename.
